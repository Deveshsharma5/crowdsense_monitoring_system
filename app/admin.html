System Modes

Monitoring Mode

Main CrowdSense operating mode. The system processes camera feeds, detects people, calculates occupancy, evaluates zones and generates safety alerts.

Calibration Mode

Configure the camera perspective and map camera coordinates to the venue floor area.

Grid / Zone Mode

Display the physical venue zones and monitor people distribution across each zone.

Alert Management

Review warnings, critical events, incidents and generated snapshots.

Local System

CrowdSense is designed to operate locally. Camera feeds, monitoring information and generated records remain on the local system unless an external network feature is intentionally configured.

Current dashboard server: http://localhost:5000

Danger Zone

These controls affect the local monitoring system. Use them only when required.
